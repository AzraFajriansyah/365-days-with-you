## 💗 About The Project

**365 Days With You** is a romantic anniversary website created as a special digital surprise.

The website brings together personal memories, heartfelt messages, photographs, music, and interactive experiences in one place.

Every section is designed to capture little moments and turn them into something worth remembering.

## ✨ Features

- **Opening Experience** — A personalized welcome screen with an interactive entrance.
- **Home Section** — An anniversary introduction with a live relationship day counter.
- **Love Letter** — A heartfelt letter that can be opened interactively.
- **Memory Gallery** — A collection of personal photographs with an interactive lightbox.
- **Memory Video** — A special video capturing meaningful moments together.
- **Relationship Timeline** — A collection of important milestones in the relationship.
- **Our Song** — A dedicated music player with animated vinyl-style artwork.
- **Reasons I Love You** — A collection of little reasons why Devina is special.
- **Secret Message** — An interactive surprise containing a personal promise.
- **Background Music** — Automatic music transitions with fade-in and fade-out effects.
- **Floating Animations** — Decorative hearts, particles, and subtle visual effects.
- **Responsive Design** — Optimized for desktop and mobile devices.
- **Accessibility Support** — Keyboard interactions and reduced-motion preferences.

## 🛠️ Built With

- HTML5 — Website structure and content.
- CSS3 — Styling, responsive layouts, and animations.
- Vanilla JavaScript — Interactive features and audio management.
- Google Fonts — DM Sans, Great Vibes, and Playfair Display.

No frameworks or external JavaScript libraries are required.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/365-days-with-you.git
```

### 2. Navigate to the Project

```bash
cd 365-days-with-you
```

### 3. Add Your Assets

Make sure all required images, audio files, and videos are placed in their corresponding directories.

Use the filenames referenced in `index.html`.

### 4. Run the Website

You can open `index.html` directly in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for a local development server.

## 🎵 Audio Configuration

The website uses two audio files:

| File | Purpose |
|---|---|
| `instrumental.mp3` | Background music |
| `lagu.mp3` | Special song for the anniversary |

The audio system includes:

- Smooth volume transitions.
- Background music controls.
- Automatic background music handling when the memory video plays.
- Separate playback states for the background soundtrack and anniversary song.

Audio playback may require an initial user interaction depending on browser autoplay policies.

## 📸 Personalization

You can customize the website by editing the following files:

| File | Description |
|---|---|
| `index.html` | Text, memories, timeline, and website content |
| `css/style.css` | Colors, typography, layouts, and animations |
| `js/main.js` | Interactive behavior, audio, and effects |

You can also replace the images, music, and video with your own personal memories.
